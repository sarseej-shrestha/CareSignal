# Contributing

CareSignal is maintained by a single owner ([@sarseej-shrestha](https://github.com/sarseej-shrestha)). All changes to this repository — including changes from the maintainer's own machine — go through a pull request into `main`, never a direct push.

## Workflow

1. Fork the repository (or create a branch, if you have been explicitly granted access).
2. Make your change on a branch named `feat/…`, `fix/…`, `docs/…`, or `test/…` describing the change.
3. Open a pull request against `main`.
4. The pull request must be reviewed and approved by the code owner before it can merge (see `.github/CODEOWNERS`).
5. No one merges their own pull request. Only the maintainer merges, after review.

## What this means in practice

- `main` is protected: no direct pushes, no force-pushes, no bypassing review — see the repository's branch protection settings.
- There are currently no other collaborators with write access to this repository. If that changes in the future, this document is the process they follow.
- Historical commit authorship in this repository's git history is not affected by this policy and will not be rewritten.

## Reporting issues

Open a GitHub issue describing the problem or proposal before submitting a pull request for anything non-trivial, so the approach can be agreed on first.
