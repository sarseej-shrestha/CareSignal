# Team Conventions

This file records the conventions this codebase has agreed on. It was created by
the `humanize-code` skill, and it's read by every subsequent run of the skill
before any audit pass.

**You can edit this file directly.** It's plain markdown. If a convention needs
to change, just edit the line below and commit. The next run of `humanize-code`
will respect the new value.

**The skill will not override anything captured here without asking you first.**

---

No conventions interview was conducted (opted out on first run). The skill will
match existing patterns where it can and ask when ambiguous, rather than
imposing an inferred style.

For reference, `CLAUDE.md` at the repo root already documents the project's
working conventions (no comments unless the WHY is non-obvious, no
speculative abstraction, no unrequested error handling, etc.) — treat that as
the closest thing this repo has to a conventions doc.
